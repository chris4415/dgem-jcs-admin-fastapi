# DG-E&M JCS-admin FastAPI v001 — Project Overview

This project is the greenfield JCS-admin control surface for DG-E&M.

It is intended to support:

- managed IT hardware discovery
- host/server profile creation
- governed script execution
- DuckDB evidence logging
- PDF/specification library harvesting
- metric discovery
- widget specification generation
- state logic and supervisory scanning
- ChatGPT API bounded orchestration

The system must not become an unmanaged script launcher.
